## The word

**Feral**

Wild, untamed, nobody in charge, and it bites. Funny on its own, true of the internet as a whole, and not the first obvious word anyone reaches for.

## How it works

`main.py` (Python 3.13, stdlib only, no network) writes the word to the output file the grader reads. It resolves the output location in this order: `ENTRY_OUT` (file or directory) → `MAKEFUN_OUTPUT_DIR` → `/output/entry.txt` → `./entry.txt`. Every run produces byte-identical output: the word and nothing else.

```sh
python3 main.py
```
